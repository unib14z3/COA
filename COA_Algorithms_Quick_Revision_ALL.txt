============================================================
PART A: MENU-DRIVEN ARITHMETIC PROGRAMS
============================================================

COMMON STARTING STEPS (for all 6 combinations):
1. Start.
2. Display a message to enter two hexadecimal numbers.
3. Accept the first number using the accept procedure and store it in A.
4. Accept the second number using the accept procedure and store it in B.
5. Display the menu.
6. Accept the user's choice.
7. If choice is 1, go to Operation 1.
8. If choice is 2, go to Operation 2.
9. If choice is 3, terminate the program.
10. If the choice is invalid, display the menu again.

COMMON ENDING FOR EACH OPERATION:
- Store the result in C.
- Display the result message.
- Call the display procedure to print the result in hexadecimal.
- Return to the menu.

A1. ADDITION + SUBTRACTION
1. Start.
2. Accept two hexadecimal numbers A and B.
3. Display menu: Addition, Subtraction, Exit.
4. Read the choice.
5. If choice is Addition:
   a. Load A into a register.
   b. Add B to A.
   c. Store the sum in C.
   d. Display the sum in hexadecimal.
   e. Return to the menu.
6. If choice is Subtraction:
   a. Load A into a register.
   b. Subtract B from A.
   c. Store the difference in C.
   d. Display the difference in hexadecimal.
   e. Return to the menu.
7. If choice is Exit, terminate.
8. Stop.

A2. ADDITION + MULTIPLICATION
1. Start.
2. Accept two hexadecimal numbers A and B.
3. Display menu: Addition, Multiplication, Exit.
4. Read the choice.
5. If choice is Addition, add A and B, store the result in C, and display it.
6. If choice is Multiplication, multiply A and B, store the lower result in C, and display it.
7. After either operation, return to the menu.
8. If choice is Exit, terminate.
9. Stop.

A3. ADDITION + DIVISION
1. Start.
2. Accept two hexadecimal numbers A and B.
3. Display menu: Addition, Division, Exit.
4. Read the choice.
5. If choice is Addition, add A and B, store the result in C, and display it.
6. If choice is Division, divide A by B. Clear the remainder register before division. Store the quotient in C and display it.
7. After either operation, return to the menu.
8. If choice is Exit, terminate.
9. Stop.

A4. SUBTRACTION + MULTIPLICATION
1. Start.
2. Accept two hexadecimal numbers A and B.
3. Display menu: Subtraction, Multiplication, Exit.
4. Read the choice.
5. If choice is Subtraction, subtract B from A, store the result in C, and display it.
6. If choice is Multiplication, multiply A and B, store the result in C, and display it.
7. After either operation, return to the menu.
8. If choice is Exit, terminate.
9. Stop.

A5. SUBTRACTION + DIVISION
1. Start.
2. Accept two hexadecimal numbers A and B.
3. Display menu: Subtraction, Division, Exit.
4. Read the choice.
5. If choice is Subtraction, subtract B from A, store the result in C, and display it.
6. If choice is Division, divide A by B after clearing the remainder register. Store the quotient in C and display it.
7. After either operation, return to the menu.
8. If choice is Exit, terminate.
9. Stop.

A6. MULTIPLICATION + DIVISION
1. Start.
2. Accept two hexadecimal numbers A and B.
3. Display menu: Multiplication, Division, Exit.
4. Read the choice.
5. If choice is Multiplication, multiply A and B, store the result in C, and display it.
6. If choice is Division, divide A by B after clearing the remainder register. Store the quotient in C and display it.
7. After either operation, return to the menu.
8. If choice is Exit, terminate.
9. Stop.

NOTE FOR ALL MENU PROGRAMS:
The accept procedure reads hexadecimal digits and converts them to a binary/numeric value by repeatedly shifting the accumulated value left by 4 bits and adding the next digit.
The display procedure converts the result into hexadecimal characters and prints them.

============================================================
PART B: BCD AND HEXADECIMAL CONVERSIONS
============================================================

B1. BCD TO HEXADECIMAL
1. Start.
2. Display a message asking for a BCD number.
3. Read the BCD number as ASCII digits.
4. Initialize accumulator to zero and set multiplier to 10.
5. For each input digit:
   a. Convert the ASCII digit into its numeric value by subtracting 30H.
   b. Multiply the accumulator by 10.
   c. Add the current digit to the accumulator.
   d. Move to the next digit.
6. Store the converted numeric value.
7. Display the result in hexadecimal using the display procedure.
8. Stop.

B2. HEXADECIMAL TO BCD
1. Start.
2. Display a message asking for a hexadecimal number.
3. Read the hexadecimal number as ASCII characters.
4. Initialize accumulator to zero and set multiplier to 16.
5. For each input character:
   a. Convert the ASCII character into its hexadecimal digit value.
   b. Multiply the accumulator by 16.
   c. Add the current digit to the accumulator.
   d. Move to the next character.
6. Store the decimal numeric value.
7. Convert the numeric value into BCD/decimal digits:
   a. Divide the value by 10.
   b. Take the remainder and convert it into an ASCII digit.
   c. Store the digit from right to left in the buffer.
   d. Repeat until the quotient becomes zero.
8. Display the resulting decimal digits.
9. Stop.

============================================================
PART C: MULTIPLICATION ALGORITHMS
============================================================

C1. SUCCESSIVE ADDITION MULTIPLICATION
1. Start.
2. Accept two hexadecimal numbers M and N.
3. Initialize answer to zero.
4. Set the loop counter to N.
5. Add M to answer repeatedly, N times.
6. Decrement the counter after each addition.
7. Repeat until the counter becomes zero.
8. Store the final answer.
9. Display the answer in hexadecimal.
10. Stop.

C2. SHIFT AND ADD MULTIPLICATION
1. Start.
2. Accept two hexadecimal numbers M and N.
3. Initialize accumulator A to zero.
4. Store M in the multiplicand register and N in the multiplier register Q.
5. Set the loop counter to the number of bits (64).
6. Check the least significant bit of Q.
7. If Q's LSB is 1, add M to accumulator A.
8. Shift Q right by one bit.
9. Transfer the LSB of A into the most significant bit of Q.
10. Shift A right by one bit.
11. Decrement the counter.
12. Repeat steps 6-11 until the counter reaches zero.
13. Display the final product using A and Q.
14. Stop.

============================================================
PART D: QUADRATIC EQUATION ROOTS USING FPU
============================================================

D1. ROOTS OF QUADRATIC EQUATION
1. Start.
2. Display a message to enter coefficients a, b, and c.
3. Read a, b, and c as floating-point values.
4. Initialize the FPU.
5. Calculate b squared (b*b) and store it.
6. Calculate 4*a*c and store it.
7. Calculate discriminant D = b*b - 4*a*c.
8. Calculate square root of the absolute value of D.
9. Calculate -b.
10. Calculate 2*a.
11. Display the roots message.
12. Calculate first root: r1 = (-b + sqrt(D))/(2*a), and display it when the program's condition permits.
13. Calculate second root: r2 = (-b - sqrt(D))/(2*a), and display it.
14. Return/terminate.
15. Stop.

============================================================
PART E: UNIVERSAL / BACKUP ALGORITHM
============================================================

This can be adapted to most assembly programs if you forget the exact algorithm:

1. Start.
2. Display the appropriate input message.
3. Accept the required input values.
4. Store the input values in memory.
5. Initialize the required registers/variables.
6. Perform the required conversion or arithmetic operation.
7. If repetition is required, initialize the counter.
8. Perform the operation inside a loop.
9. Update the registers/variables and counter.
10. Repeat until the required condition is satisfied.
11. Store the final result.
12. Convert the result into the required output format.
13. Display the result.
14. Terminate the program.
15. Stop.

============================================================
VERY QUICK MEMORY CUES
============================================================

Menu arithmetic:
Input A,B -> Menu -> Choice -> Operation -> Store C -> Display -> Menu again -> Exit.

BCD to Hex:
Read decimal digits -> accumulator = accumulator*10 + digit -> display hex.

Hex to BCD:
Read hex digits -> accumulator = accumulator*16 + digit -> repeatedly divide by 10 -> collect remainders -> display decimal digits.

Successive Addition:
Answer=0 -> repeat N times: Answer=Answer+M.

Shift-and-Add:
A=0, M=multiplicand, Q=multiplier -> check Q LSB -> add M if 1 -> shift Q right -> move A LSB into Q MSB -> shift A right -> repeat 64 times.

Quadratic:
Read a,b,c -> D=b^2-4ac -> sqrt(D) -> -b -> 2a -> roots (-b±sqrt(D))/(2a) -> display.

============================================================
PART F: STRING OPERATIONS (20 COMBINATIONS)
============================================================

COMMON STRING PROGRAM FLOW (applies to every combination):
1. Start.
2. Display prompt and accept String1.
3. Read the string, remove newline, and store its length in L1.
4. Display prompt and accept String2.
5. Read the string, remove newline, and store its length in L2.
6. Display the menu containing the three selected string operations and Exit.
7. Read the user's choice.
8. If choice matches an operation, perform it and display the result.
9. Return to the menu after the operation.
10. If Exit is selected, terminate. If invalid choice, display an error and return to menu.
11. Stop.

STRING OPERATION ALGORITHMS (learn these six; combinations only select 3):

F1. STRING LENGTH
1. Start.
2. Read String1 and determine/store its length L1 while reading.
3. Display the length label.
4. Convert L1 to decimal digits and display it.
5. Return to menu.
6. Stop.

F2. STRING COPY
1. Start.
2. Set source pointer to String1 and destination pointer to String3.
3. Set counter to L1.
4. Copy one character from source to destination.
5. Increment source and destination pointers and decrement counter.
6. Repeat until counter is zero.
7. Display String3 as the copied string.
8. Return to menu.
9. Stop.

F3. STRING REVERSE
1. Start.
2. Set source pointer to the last character of String1 (start + L1 - 1).
3. Set destination pointer to String3 and counter to L1.
4. Copy the character at source to destination.
5. Decrement source pointer, increment destination pointer and decrement counter.
6. Repeat until counter becomes zero.
7. Display String3 as the reversed string.
8. Return to menu.
9. Stop.

F4. STRING COMPARE
1. Start.
2. Compare the lengths L1 and L2.
3. If lengths differ, display “Strings are not equal” and return to menu.
4. If lengths are equal, compare characters of String1 and String2 one by one.
5. If any character differs, display “Strings are not equal”.
6. If all characters match, display “Strings are equal”.
7. Return to menu.
8. Stop.

F5. STRING CONCATENATE
1. Start.
2. Set source pointer to String1 and destination pointer to String3.
3. Set counter to L1 and copy all characters of String1 into String3.
4. Set source pointer to String2; destination remains after copied String1.
5. Set counter to L2 and copy String2 after String1.
6. Calculate combined length L3 = L1 + L2.
7. Display String3 for L3 characters as the concatenated string.
8. Return to menu.
9. Stop.

F6. PALINDROME CHECK
1. Start.
2. Set source pointer to the last character of String1.
3. Set destination pointer to String3 and counter to L1.
4. Copy String1 into String3 in reverse order.
5. Compare original String1 with reversed String3 character by character.
6. If all characters match, display “String is palindrome”.
7. Otherwise display “String is not palindrome”.
8. Return to menu.
9. Stop.

============================================================
STRING OPERATIONS - UNIVERSAL BACKUP ALGORITHM
============================================================

1. Start.
2. Accept the required string input(s).
3. Determine and store the length(s).
4. Display the menu and accept the choice.
5. Initialize source pointer, destination pointer, and counter as required.
6. Perform the selected string operation character by character.
7. Update pointers and counter after each character.
8. Repeat until all characters are processed.
9. For compare/palindrome, check whether characters match and decide the result.
10. Display the result.
11. Return to menu or terminate when Exit is selected.
12. Stop.

QUICK MEMORY CUES:
Length: count characters / use stored L1.
Copy: forward copy String1 -> String3.
Reverse: start from last character -> copy backward into destination.
Compare: lengths first, then character-by-character.
Concatenate: copy String1, then String2 immediately after it; L3=L1+L2.
Palindrome: reverse String1, compare original and reversed; equal means palindrome.

EXAM TIP:
The 20 combinations are not 20 unique algorithms. Learn the common menu flow and these 6 operation algorithms. For the given combination, write only the three corresponding operation steps.
